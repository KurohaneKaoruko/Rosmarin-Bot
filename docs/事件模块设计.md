# 事件模块设计

## 基本信息
- 功能定位：提供全局可调用的延时/条件事件调度器，用于跨模块轻量编排。
- 设计模式：事件队列（`Map` 存储）、生命周期分发（`start/tick/end`）、快照遍历（防止同轮新增事件立刻执行）。
- 运行节奏：`EventModule.init` 挂载 API；`start/tick/end` 分别调用 `runEventPhase(...)`。
- 数据边界：事件数据仅驻留运行时内存（`events: Map`），不持久化到 `Memory`。

## 对外 API（`global.event`）
- `add(spec)`：添加事件并返回 `event:<tick>:<seq>`。
- `cancel(id)`：取消事件。
- `get(id)`：获取事件副本。
- `list(phase?)`：列举事件副本。

## 事件定义
- `when`：数字（延后 N tick）或函数（条件触发）。
- `life`：`start | tick | end`，默认 `tick`。
- `maxRuns`：最大执行次数，默认 `1`。
- `stopWhen`：终止条件函数，返回 `true` 即删除事件。
- `exec`：执行函数（必填）。
- `data`：事件运行时上下文透传数据。

## 执行语义
1. 每个阶段开始时快照 `ids = Array.from(events.keys())`。
2. 逐条检查：阶段匹配、次数上限、`when` 是否满足。
3. 执行 `exec`，成功后 `runCount += 1`。
4. 满足 `maxRuns` 或 `stopWhen` 即删除。

## 异常策略
- `exec` 抛错：记录日志并删除该事件（避免反复报错）。
- `stopWhen` 抛错：视为终止并删除（fail fast）。
- `when` 抛错：本轮跳过，不删除。

## 示例
```ts
global.event.add({
  life: 'tick',
  when: 10,
  maxRuns: 2,
  exec: ({ runCount, data }) => console.log(runCount, data),
  data: { from: 'demo' }
})
```
