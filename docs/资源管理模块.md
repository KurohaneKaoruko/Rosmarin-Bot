# 资源管理功能

## 基本信息
- 功能定位：统一协调多房间资源平衡、生产原料补给、终端发送任务下发与异常回收。
- 设计模式：规划-执行分离（`ResourceManage.tick` 只下发任务，`TerminalWork` 执行发送）、启发式匹配（富余源 × 缺口目标）、动态阈值调节。
- 运行节奏：`ResourceManage.tick` 每 50 tick 执行一次全局调度。
- 数据边界：配置来自 `RESOURCE_BALANCE` + `Memory.RosmarinBot.ResourceManage`；任务落在各房 `missionPools.terminal(send)`。

## 核心流程
1. 构建候选房：仅纳入可用 `storage + terminal` 且满足条件的房间。
2. 计算阈值：按资源维度形成每房 `[targetThreshold, sourceThreshold]`。
3. 识别供需：生成 `ResManageMap[res].source/target`。
4. 生产需求注入：把 lab/factory 自动生产缺口写入 `prodNeeds`，提升原料调度优先级。
5. 调度配对：按“源富余高→目标缺口大”进行发送任务 upsert。

## 调度策略细节
- 成本感知：使用 `getTransactionCostRatio` 缓存估算跨房传输成本，过滤高损耗配对。
- 限流：`perPairCap/perSourceCap/perSourceMaxPairs` 防止单房任务爆炸。
- 去重：把“已排队发送量”计入 `queuedIn/queuedOut`，避免同 tick 重复下单。
- 资源安全：目标房若处于防御不安全窗口（`resourceUnsafeUntil`）会拒绝转入。

## 异常与恢复
- 停滞任务：缺料超时任务会被标记移除，防止队列长期堵塞。
- 动态阈值：长期缺口会降低阈值，供给恢复后缓慢回升。
- 低效率保护：房间产线效率持续偏低时，暂停生产相关投喂并记录恢复窗口。

## 对外控制接口
- `resource.manage.set/remove/clear/show`：维护房间级资源阈值。
- `resource.transport.task`：手动下发结构间搬运任务（`storage/terminal/factory`）。

## 当前实现边界
- 配对策略是启发式贪心，不保证全局最优运输成本。
- 阈值调节为经验参数，需结合 shard 规模持续校准。
