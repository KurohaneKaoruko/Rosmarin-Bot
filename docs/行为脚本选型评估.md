# 行为脚本选型评估（非状态机）

## 评估基准
- **行为树**：高频分支、战斗响应、需要随时热插拔子树。
- **策略模式**：算法族可替换、线性流程但分支清晰、希望通过 DI 容器统一注册。
- **函数式管道**：决策与副作用严格分离，纯函数占比高，适合“采集/执行”类流程。
